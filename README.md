# 💰 Трекер расходов

Веб-приложение на Flask для учёта личных расходов с графиками и тёмной темой.

## 🚀 Живой сайт



## ✨ Возможности

- ➕ **Добавление расходов** — сумма, категория, дата, комментарий
- 📋 **Список расходов** с фильтрами: сегодня, неделя, месяц, всё время
- 🗑 **Удаление** записей
- 💵 **Итоговая сумма** за выбранный период
- 📊 **Круговая диаграмма** расходов по категориям
- 🌙 **Тёмная и светлая тема** с сохранением выбора
- 🎨 **Цветные бейджи** категорий
- 📱 **Адаптивный дизайн** — работает на телефоне

## 🛠 Технологии

- **Python 3** — язык программирования
- **Flask** — веб-фреймворк
- **SQLite** — база данных
- **matplotlib** — построение графиков
- **Jinja2** — шаблонизатор
- **HTML/CSS/JavaScript** — интерфейс
- **Render** — хостинг
